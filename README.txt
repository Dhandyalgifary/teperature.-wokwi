project ini adalah project untuk arduino uno
bisa di simulasikan di wokwi (https://wokwi.com/)
project ini berfungsi untuk mengukur suhu ruangan dengan sensor DS18B20 dan menampilkan suhunya di lcd(l2c)

bahan/alat yang digunakan 
1. ARDUINO UNO 
2. sensor suhu DS18B20
3. BUZZER (opsional)
3. 2 lampu led (opsional)
4. 1 resistor 4.7k ohm
5. 2 resistor 220 ohm (opsional jika menggunakan led)
6. lcd 16x2 (l2c)
